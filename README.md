# 361-Project-
This the Taste City app, a restaurant recommendation service.

Communication Contract: 
-How to programmatically REQUEST data:
Run it locally, use a request via http://localhost:5252/sort-data. With sample data, you can sort by title, date, or order number. 

-How to programmatically RECEIVE data: 
Receive the data via the post request locally, it will be sorted and sent back to the client.
